Excel 模板字段说明

日期格式：YYYY-MM-DD（如 2026-05-04） |  百分比填小数：45% 填 0.45

Sheet 01 · 投流获客

date日期 channel渠道名称（唯一标识） spend消耗（元，填纯数字） impressions展现量（人次） leads留资量 daily_new日增 delta_pct环比变化（小数或整数均可，0.08 或 8 均表示+8%）

Sheet 02 · 自媒体矩阵

date / channel日期、渠道名 posts / views / interactions发文数、浏览量、互动数 reposts / followers / follower_growth复用、粉丝总量、粉丝日增 leads_gen / delta_eng获客数、互动率环比（小数/整数均可）

Sheet 03 · 客户活动

date / name日期、活动名（唯一标识） scale / registrations / checkins / orders规模、报名、签到、落单人数 order_amount落单金额（万元）

Sheet 04 · AI推荐监测

date / platform日期、平台名 mention_rate / top3_rate / avg_rank / neg_rate提及率、前三率、均排名、负面率（小数） delta_top3 / keywords前三率环比、高频词（词:次数,词:次数）

Sheet 05 · 舆情监控

date / scope日期、domestic 或 overseas total / pos_pct / neu_pct / neg_pct总数、正/中/负占比（三项之和=1） news_1_title … news_6_title新闻标题（可填URL，格式：标题|http://...） news_1_sentiment … news_6_sentimentpos / neu / neg

Sheet 06 · 战略进度

task任务名称（唯一标识） description / deadline描述、截止日期 statusdone / in_progress / at_risk / not_started progress进度小数（0.75 = 75%）
